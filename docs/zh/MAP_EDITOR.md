# 地图编辑器

地图编辑器用于创建与修改 Reinforce Tactics 的游戏地图。

## 功能

- **新建地图**：从零设计自定义尺寸地图（最小 20×20）
- **编辑已有地图**：从 maps 目录加载并修改
- **图块调色板**：6 种地形 + 3 种建筑
- **玩家归属**：将建筑、塔、总部分配给玩家 1–4
- **可视化编辑**：左键绘制、右键擦除，支持网格叠加
- **地图校验**：保存前确保每位玩家恰好一个总部
- **多语言**：英语、法语、韩语等

## 入口

主菜单选择 **「地图编辑器」**：

- **新建地图**：自定义尺寸
- **编辑已有地图**：加载并修改

## 操作

### 鼠标

- **左键**：绘制当前图块
- **右键**：擦除（替换为草地）
- **滚轮**：滚动/平移地图
- **悬停**：查看坐标

### 键盘快捷键

- **Ctrl+S**：保存
- **G**：切换网格
- **+/-**：缩放
- **1–9**：快速选择图块类型
  - 1：草地
  - 2：海洋
  - 3：水域
  - 4：山地
  - 5：森林
  - 6：道路
  - 7：塔
  - 8：建筑
  - 9：总部
- **Esc**：退出编辑器

## 图块类型

### 地形

- **草地** (p)：可通行
- **海洋** (o)：不可通行
- **水域** (w)：不可通行
- **山地** (m)：可通行（弓箭手站在山上攻击距离 +1）
- **森林** (f)：可通行
- **道路** (r)：可通行

### 建筑

- **塔** (t)：中立或玩家所属，每回合收入 $50
- **建筑** (b)：中立或玩家所属，每回合收入 $100
- **总部** (h)：中立或玩家所属，每回合收入 $150（每位玩家必须恰好 1 个）

## 地图格式

地图以 CSV 保存，使用图块代码：

- 地形单字母：`p`、`o`、`w`、`m`、`f`、`r`
- 中立建筑（无主）：`t`、`b`、`h`
- 带归属：`h_1`、`b_2`、`t_3`

示例：

```
o,o,o,o,o
o,p,p,p,o
o,p,h_1,p,o
o,b,t,b,o
o,o,o,o,o
```

其中 `h_1` 为玩家 1 总部，`b` 与 `t` 为中立建筑，对局中可被任意玩家占领。

## 地图要求

有效地图需满足：

1. 最小尺寸：20×20
2. 每位玩家恰好一个总部（`h_1`、`h_2` 等）
3. 自动保存到 `maps/1v1/`（2 人）或 `maps/2v2/`（4 人）

## 提示

- 先铺底图（海洋或草地）再细化
- 总部放角落有利于平衡
- 中立塔放在战略中心
- 用山地、森林制造战术选择
- 做完后自己对局测试！
