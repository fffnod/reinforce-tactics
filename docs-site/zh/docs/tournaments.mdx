# Bot 锦标赛

欢迎来到 Reinforce Tactics Bot 锦标赛页面！本页跟踪不同类型 Bot 之间的官方锦标赛结果，展示规则 Bot、LLM 驱动 Bot 与已训练 RL 模型的表现。

## 什么是锦标赛？

Reinforce Tactics 中的锦标赛以循环赛形式让不同类型的 Bot 相互对战。每组对阵包含多局对局，Bot 交替作为玩家 1 与玩家 2，以抵消先手优势。

### 锦标赛格式

- **循环赛**：每个 Bot 与每个其他 Bot 对战
- **公平对战**：每个 Bot 作为玩家 1 与玩家 2 的对局数相等
- **地图**：通常在 6x6 新手地图上进行快速对局
- **结果**：胜/负/平记录与胜率统计

## Bot 类型

### SimpleBot
遵循简单策略的规则 AI：
- 优先购买最贵单位（每回合一个）
- 优先占领建筑与塔楼
- 攻击附近的敌方单位
- 始终包含在锦标赛中

### MediumBot
策略更复杂的改进型规则 AI：
- **最大化单位购买**：每回合购买多个单位，而非仅一个
- **协调攻击**：计划集火，在一回合内击杀敌人
- **智能优先级**：优先占领离己方 HQ 最近的建筑
- **打断占领**：攻击正在占领建筑的敌人
- **高效战斗**：评估伤害/费用比以做出更好的攻击决策
- 默认与 SimpleBot 一同包含在锦标赛中

### AdvancedBot
扩展 MediumBot 的高度复杂 AI，具备增强战略能力：
- **继承 MediumBot**：基于 MediumBot 经过验证的协调攻击与占领策略
- **增强单位编成**：跨全部 8 种单位类型的优化购买（25% Warriors、20% Archers、15% Mages、10% Knights、10% Rogues、8% Barbarians、7% Clerics、5% Sorcerers）
- **山脉站位**：攻击前将单位部署在山脉上以获得加成伤害
- **智能远程战斗**：优先使用 Archer 与 Mage 远程攻击以减少反击伤害
- **特殊能力使用**：有效对高价值目标使用 Mage 麻痹，对受伤前线单位使用 Cleric 治疗
- **地图意识**：首回合分析 HQ 位置与防守山脉位置
- **激进战术**：更激进的攻击优先级与敌人追击
- 默认与 SimpleBot、MediumBot 一同包含在锦标赛中

### MasterBot
扩展 AdvancedBot 的大师级脚本 Bot，带有针对性升级：
- **继承 AdvancedBot**：保留完整游戏阶段状态机、克制矩阵、撤退阈值与特殊能力编排
- **威胁图**：每回合计算一次每格预期受到伤害，用于撤退格子选择与 Knight 冲锋落点——避免走进交叉火力，同时不偏向前压交战
- **按 HP 升序集火**：串联攻击者时，最低 HP 的友军先出手，使受伤攻击者在可能被反击击杀前打出最后一击
- **HQ 狙击优先级**：在征服阶段，敌方 HQ 优先于等距塔楼，使每个单位推动胜利条件
- **加速跟进**：已加速单位在已占领/攻击/冲锋后仍可执行第二次行动——实现双占领、双冲锋与 Barbarian 跨图机动

### MixedBot
课程桥接 Bot，非独立策略：
- **构造时采样两个 Bot 之一**（例如 `easy=simple`、`hard=medium`），概率为 `p_hard`
- **按 episode**：每个 episode 全程以被采样的 Bot 进行（无 episode 中途切换），从而在选中更难 Bot 的 episode 中保留其多回合策略
- 用作 bootstrap 课程中的垫脚石（`configs/ppo/bootstrap.yaml`）——例如 `simple → medium` 与 `medium → advanced` 桥接

### LLM Bot
由大语言模型驱动的 AI：
- **OpenAIBot**：由 GPT 模型驱动
- **ClaudeBot**：由 Anthropic 的 Claude 驱动
- **GeminiBot**：由 Google 的 Gemini 驱动
- 使用自然语言推理做出战略决策

### Model Bot
使用强化学习训练：
- 使用 Stable-Baselines3（PPO、A2C 或 DQN）
- 通过自对弈与对手挑战进行训练
- 通过经验学习最优策略

#### 分析

**关键发现：**

1. **AdvancedBot 占据主导**：AdvancedBot 表现极为出色，胜率 75%，ELO +193。其复杂策略（山脉站位、远程战斗、特殊能力）证明非常有效。

2. **MediumBot 表现稳健**：胜率 39.6%，ELO +75，MediumBot 展现了协调攻击与最大化单位生产相对于 SimpleBot 基础打法的价值。

3. **LLM Bot 表现挣扎**：Claude Haiku 垫底，胜率仅 4.2%（ELO -173）。这表明当前 LLM 推理可能尚未针对此游戏格式所需的战术决策优化。

4. **高平局率**：许多对局以平局结束，尤其是在 center_mountains.csv（防守地形）以及表现较差的 Bot 之间。这表明游戏的战略深度与防守可行性。

5. **地图影响**：AdvancedBot 在 beginner.csv 与 corner_points.csv 上主导（100% 胜率），而 MediumBot 在 funnel_point.csv 上表现更佳。

**值得注意的观察：**
- AdvancedBot 在 4 张地图中的 3 张上从未落败
- 实力层次清晰：AdvancedBot > MediumBot > SimpleBot/Claude Haiku
- Center mountains 地图产生最多平局（防守地形优势）

- 常见错误与陷阱

### Bot 优势与劣势

每种 Bot 类型有不同特点：
- **SimpleBot**：可预测但稳定；会犯基础战略错误
- **MediumBot**：比 SimpleBot 更有策略；使用协调战术与更好的单位购买
- **AdvancedBot**：扩展 MediumBot，具备增强单位编成、山脉站位、远程战斗优先级与特殊能力使用
- **MasterBot**：扩展 AdvancedBot，具备威胁图、按 HP 升序集火、HQ 狙击优先级与加速跟进
- **MixedBot**：仅用于课程——每个 episode 采样 easy/hard 内部 Bot 用于 bootstrap 训练
- **LLM Bot**：有创意但有时不可预测
- **Model Bot**：经过优化但可能对训练条件过拟合

### 分地图表现

不同地图偏爱不同策略：
- 小地图（6x6）：快速、激进打法
- 中地图（10x10）：经济/军事平衡
- 大地（24x24+）：长期战略与站位
