# 地图

Reinforce Tactics 提供多种为不同游戏模式与玩家数量设计的地图。每张地图通过地形布局、建筑放置与关口提供独特的战略挑战。

## 地图图例

- **绿色** - 平原（可行走地形）
- **深绿色** - 森林（提供防御加成）
- **蓝色** - 水域/海洋（不可通行）
- **灰色** - 山脉（可行走，Archer 站在山脉上时攻击射程 +1）
- **棕色** - 道路（移动更快）
- **红色** - 玩家 1 建筑
- **蓝色调** - 玩家 2 建筑
- **绿色调** - 玩家 3 建筑
- **白色/浅灰** - 中立塔楼/建筑

### 其他 1v1 地图

仓库在 `maps/1v1/` 下还附带了更多 1v1 地图——这些是专注于训练与探测的地图，供 Bot 基准测试与行为克隆场景使用。预览图即将推出。

| 地图 | 用途 |
|-----|---------|
| `starter.csv` | 极简地图，用于首次游玩与冒烟测试 |
| `intermediate.csv` | 中等尺寸地图，衔接新手图与全尺寸战场 |
| `skirmish.csv` | PPO/BC 遭遇战探测使用的单图轨道 |
| `last_stand.csv` | 强调 HQ 防守的防御场景 |
| `mage_showdown.csv` | 紧凑地图，用于练习 Mage 麻痹交互 |
| `cleric_vigil.csv` | 用于练习 Cleric 治疗/治愈决策的地图 |
| `sorcerer_cabal.csv` | 突出 Sorcerer 加速/增益连招的地图 |
| `cavalry_charge.csv` | 开阔地形，奖励 Knight 冲锋打法 |
| `rogue_flank.csv` | 用于突出 Rogue 侧翼站位的地图 |
| `mountain_snipers.csv` | 山脉密集地图，用于 Archer 山脉射程加成 |

## 创建自定义地图

想创建自己的地图？使用内置地图编辑器，可在 GUI 模式的主菜单中访问：

```bash
python3 main.py --mode play
# Then select "Map Editor" from the main menu
```

详见 [地图编辑器指南](https://github.com/kuds/reinforce-tactics/blob/main/docs/MAP_EDITOR.md) 了解详细说明。

### 地图要求

- 最小尺寸：6x6 格子
- 每位玩家必须恰好有一个总部（HQ）
- 所有玩家对中立建筑应有大致相等的访问权
- 放置地形特征时需考虑平衡性
