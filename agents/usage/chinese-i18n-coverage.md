# 中文界面汉化覆盖说明

**分类**：使用类
**相关代码**：`reinforcetactics/utils/language.py`，局内菜单与 HUD
**状态**：已补全主要玩家可见文案（单位行动菜单等）

---

## 1. 问题

切换中文后，部分界面（尤其是选中单位后的 **移动/攻击/待命** 等操作菜单）仍显示英文，因为文案写死在 Python 里，未走 `language.get()`。

---

## 2. 已处理范围

| 区域 | 说明 |
|------|------|
| 单位行动菜单 | 攻击、麻痹、治疗、驱散、加速、攻防强化、占领、取消移动、待命 |
| 购买单位菜单 | 标题 + 八种兵种中文名 + 费用后缀「金」 |
| 悬停提示 | 可移动 / 可行动 / 麻痹 / 生命攻击防御 |
| 玩家配置 | 机器人难度名、无 API Key、浏览 |
| 设置 | 图形 / 单位 / API 密钥 / 声音未实现 / 全开开关 |
| 地图编辑器 | 中文键补全（此前缺失约 34 条） |
| 确认对话框 | 默认提示 Y/N |

快捷键字母 **(A)(W)** 等保留，方便对照操作。

---

## 3. 仍可能为英文的地方

- 地图 **文件名 / 地图元数据名称**（来自 CSV/资源，非 UI 词条）
- 部分调试输出、控制台 `print`
- 法文/韩文/西班牙文中与本次新增键未同步的条目（会回退到代码里的英文 default）
- 品牌名 `REINFORCE TACTICS` / 作者名刻意保留原文

---

## 4. 如何继续补词条

1. 在 `language.py` 的 `"english"` / `"chinese"` 字典中增加键。
2. UI 使用 `get_language().get("your.key", "English fallback")`。
3. 避免硬编码展示字符串。
